# TripWise – Your All-in-One Smart Travel Planner

TripWise is a smart travel planning web application that helps users discover destinations, explore places, check weather conditions, and organise their travel plans in one place.

## Features

* Search and explore travel destinations
* Discover places and attractions
* View current and forecast weather information
* Build and manage a personalised travel plan
* Save trip information using browser storage
* Responsive and accessible user interface
* Dynamic content powered by external APIs

## Technologies

* HTML5
* CSS3
* Vanilla JavaScript
* JavaScript ES Modules
* External REST APIs
* LocalStorage

## Project

This project was created as an individual final project for WDD 330 – Web Frontend Development at BYU-Idaho.
