# TripWise – Your All-in-One Smart Travel Planner

TripWise is a smart travel planning web application that helps users discover destinations, explore places, check weather conditions, and organise their travel plans in one place.

## Features

* Search and explore travel destinations
* Discover places and attractions
* View current and forecast weather information
* Build and manage a personalised travel plan
* Save trip information using browser storage
* Responsive and accessible user interface
* Dynamic content powered by external APIs

## Technologies

* HTML5
* CSS3
* Vanilla JavaScript
* JavaScript ES Modules
* External REST APIs
* LocalStorage

## Project

This project was created as an individual final project for WDD 330 – Web Frontend Development at BYU-Idaho.

**Project name:** TripWise – Your All-in-One Smart Travel Planner

## APIs Used

TripWise uses external APIs to provide dynamic travel information.

- REST Countries API — provides country information such as capital, region, population, area, currencies, languages, and flags.
- Open-Meteo — provides current weather information for destination capitals.
- Wikipedia — provides additional information about places and attractions when available.
- Geoapify Places API — provides places and attractions to explore within destinations.

The API data is retrieved with JavaScript and used to dynamically update the application.

## Project Structure

The project is organized into separate HTML, CSS, and JavaScript files.

The JavaScript is divided into modules based on functionality, including destination information, weather, places, trip planning, storage, and shared utilities.

This structure makes the application easier to maintain and allows individual features to be developed and updated separately.

## Local Storage

TripWise uses browser local storage to save information between visits.

It stores favourite destinations and saved trip/itinerary information so users can return to their plans later without losing their data.
